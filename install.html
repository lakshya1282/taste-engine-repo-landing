SETUP DISPATCH

Install Taste Engine.

It’s one file called SKILL.md. Put it in your agent’s skills folder and you’re done.

Step 0: Get the file

Download SKILL.md directly from the repository, or clone it via git:

TERMINAL 
git clone https://github.com/lakshya1282/taste-engine.git

Antigravity (IDE or App), all projects

Installs Taste Engine globally across all workspaces in Antigravity.

BASH / ZSH 
mkdir -p ~/.gemini/config/skills/taste-engine
cp SKILL.md ~/.gemini/config/skills/taste-engine/SKILL.md
POWERSHELL 
New-Item -ItemType Directory -Force "$HOME\.gemini\config\skills\taste-engine"
Copy-Item SKILL.md "$HOME\.gemini\config\skills\taste-engine\SKILL.md"

Note: Older setups may use ~/.gemini/antigravity/skills/, which is also fully supported.

Antigravity, one project only

Scope Taste Engine to a single repository:

PATH 
<your-project>/.agents/skills/taste-engine/SKILL.md

The older folder path .agent/skills/ also works seamlessly.

Antigravity CLI (`agy`)

Global skills path:

CLI PATH 
~/.gemini/antigravity-cli/skills/taste-engine/SKILL.md

Or if packaged as an agy plugin:

AGY CLI 
agy plugin install https://github.com/lakshya1282/taste-engine.git

Claude Code

For all projects:

BASH 
mkdir -p ~/.claude/skills/taste-engine
cp SKILL.md ~/.claude/skills/taste-engine/SKILL.md

For a single project:

PATH 
.claude/skills/taste-engine/SKILL.md

Note: Taste Engine works best when Claude Code has a browser tool available (e.g. Chrome DevTools or Puppeteer MCP) plus terminal access.

Claude App

Zip a folder named taste-engine that contains SKILL.md, then upload it under:

Settings → Capabilities → Skills

[Confirm availability on your plan and test this before publishing.]

Other Agents

If your agent supports the Agent Skills format, copy the taste-engine folder (containing SKILL.md) into its skills directory.

If it doesn't support skills natively, paste the raw markdown contents of SKILL.md into its system prompt, rules, or custom instructions file. You can simply invoke it by saying: "Follow the taste-engine process."

SHELL UTILITY

Optional automated install script

A simple cross-platform bash script to detect and install for both Antigravity and Claude Code:

install.sh 
#!/usr/bin/env bash
set -e
NAME=taste-engine
if [ -d "$HOME/.gemini" ]; then
  mkdir -p "$HOME/.gemini/config/skills/$NAME"
  cp SKILL.md "$HOME/.gemini/config/skills/$NAME/SKILL.md"
  echo "Installed for Antigravity"
fi
if [ -d "$HOME/.claude" ]; then
  mkdir -p "$HOME/.claude/skills/$NAME"
  cp SKILL.md "$HOME/.claude/skills/$NAME/SKILL.md"
  echo "Installed for Claude Code"
fi

Always review any script before executing it in your shell.

AUDIT CHECKLIST

Verify it worked

System Requirements

  • An agent supporting Agent Skills or custom rules
  • A browser tool (strongly recommended for seed crawls)
  • Terminal access for dice rolls and local previews
  • Active internet connection for reference measurement

Updates & Uninstall

To Update: Download the latest SKILL.md and overwrite the file in your skills directory. Start a fresh conversation session.

To Uninstall: Delete the taste-engine folder.

🛡 Safety & Execution Etiquette

Taste Engine makes your agent browse public websites and run small calculation scripts in your terminal. It reads robots.txt, throttles requests slowly, and never attempts to bypass logins or bot challenges. Your agent’s own permission boundaries remain in full effect. Always review commands before approving them.
