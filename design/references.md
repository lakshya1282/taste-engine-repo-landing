# Reference Scan

Calibrating against 5 distinct references to establish craft standards, identify cliches to avoid, and define the market gap.

## Reference 1: Risotto Studio (`risottostudio.com`)
- **World:** Wildcard — Zine & Risograph print workshop (Glasgow, UK).
- **Concept:** A loud, unapologetic digital print-bed celebrating tactile ink layers, paper grain, and mechanical registration imperfections.
- **Fonts:** Heavy grotesque display with exaggerated ink-traps paired with a neutral functional text face.
- **Palette:** High-impact neon spot colors (fluorescent orange, vivid aqua, sunflower yellow) stamped onto uncoated newsprint off-white.
- **Motion:** Staccato micro-hops, instant hover fills, paper sheet drop animations.
- **Craft Detail:** Real registration mark crosshairs `+` that shift slightly on cursor move like misaligned print cylinders.

## Reference 2: Actual Source (`actualsource.work`)
- **World:** Wildcard — Independent publisher, design book studio, and clothing brand.
- **Concept:** Ultra-sparse spatial index where every book and object is treated as an architectural artifact in an open exhibition space.
- **Fonts:** Custom editorial sans with razor-sharp glyph cuts; stark contrast between 96pt headlines and 11px catalog metadata.
- **Palette:** Cool sterile gallery gray (`#ebebeb`) with intense black ink typography and occasional electric red stickers.
- **Motion:** Zero fluff; instant transitions, smooth inertial dragging on image sheets, strict spatial geometry.
- **Craft Detail:** Interactive canvas where items can be inspected, moved, and examined with catalog coordinates.

## Reference 3: MSCHF (`mschf.com`)
- **World:** Polarizing / Weird internet culture collective.
- **Concept:** Radical conceptual drops presented through an absurdly direct, non-standard digital museum interface.
- **Fonts:** Raw industrial gothic mixed with hand-drawn marker notes and urgent warning callouts.
- **Palette:** Stark white and industrial warning orange with aggressive high-contrast black borders.
- **Motion:** Physics-based collisions, draggable interactive widgets, spring-loaded buttons that pop.
- **Craft Detail:** The entire page is a living interactive toy rather than a marketing funnel; visitor exploration is intrinsically rewarded.

## Reference 4: Val Town (`val.town`)
- **World:** Developer tool & modern coding environment.
- **Concept:** Social coding notebook built around lightweight executable functions and community modules.
- **Fonts:** Clean technical grotesk (`Schibsted / Favorit` style) paired with monospace code blocks.
- **Palette:** Crisp clean light paper backdrop with subtle border dividers and high-contrast syntax highlighting.
- **Motion:** Subtle, immediate feedback on copy actions, frictionless tab switching, snappy state changes.
- **Craft Detail:** Interactive copy-paste snippets that provide instant tactile gratification when clicked.

## Reference 5: Obys Agency: "Grids" (`grids.obys.agency`)
- **World:** Awwwards Developer Award winner (interactive editorial design experiment).
- **Concept:** Interactive masterclass exploring graphic design grids through kinetic typography and dimensional plane manipulation.
- **Fonts:** Monumental variable grotesk with extreme width variations.
- **Palette:** Monochromatic charcoal and light plaster with electric vermilion accents.
- **Motion:** GSAP ScrollTrigger timeline scrubbing, letterform assembly, spatial distortion on drag.
- **Craft Detail:** Visual guidelines that reveal layout geometry live as you hover and scroll.

---

## Synthesis: The Craft Gap (under 120 words)
The best sites share tactile confidence: real physical metaphors (print beds, spatial coordinates, kinetic toys), non-linear spatial navigation, and deliberate friction that demands curiosity.
What is tragically overused right now: dark-mode purple/gold "SaaS slop", fake metrics counters, floaty 3D glass spheres, and sterile 3-column feature grids.
**The Gap Taste Engine Will Own:** A tactile "Zine Studio meets Spatial Command Deck" in crisp cool monochrome with electric hyper-orange accents, an interactive Spatial Zone Map, a rollable 3D logo die, and hand-annotated marker corrections that directly mock AI cliches while delivering a razor-sharp, zero-bloat install experience.
